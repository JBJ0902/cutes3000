UP 경쟁 업데이트

실행: 기존 서버 종료 -> 압축 해제 -> game_src/START_GAME.bat 실행(Python 필요).
http://localhost:8000 에서 Ctrl+F5. 기존 진행은 같은 브라우저/주소/포트에서 유지됩니다.
교체 전에 메뉴에서 저장 파일을 내보내 두세요.

음악: 화면 우측 하단에 스크롤을 따라가는 접이식 메뉴. 게임을 열면 접힌 상태이며 음악은 유지됩니다.
곡명: 개의 꿈 -> 3000개의 꿈.
중복 닉네임: 날짜별 문구에 들어 있던 옛 닉네임 접두사를 제거하고 메시지만 표시합니다.
합방: 4가지 포맷 각 12개 질문(총 48개). 질문 묶음을 모두 사용하기 전 재등장하지 않으며 답 위치도 섞입니다.
별풍선: 12가지 상황/수량/문구, 4가지 리액션. 실제 결제와 무관한 게임 이벤트입니다.

스트리머 콘텐츠 참여:
- 가상 외부 크루 지원자 6명과 경쟁하는 1회 선발전(2라운드 없음).
- 매번 18~28초. 스페이스 또는 UP 버튼 클릭 한 번에 +1 UP.
- 스페이스 누르고 있기 자동 반복은 제외. 탭을 벗어나면 플레이와 경쟁자 시간이 멈춥니다.
- 순위는 실시간 표시. 동점은 외부 지원자 우선이며 상위 3명만 선발됩니다.
- 성공하면 6가지 콘텐츠 중 한 곳에 초대되어 참여 선택을 진행합니다.
- 협동 선택: 충성도 +5 / 즐겨찾기 +2. 도전 선택: 화제성 +6 / 체력 -2.
- 참가 결과와 최종 UP/순위는 일일 결과와 저장 데이터에 기록됩니다.
- 실패해도 응원 활동 기본 보상이 있으며 참여 추가 보상은 없습니다.
- 취소하면 날짜/능력치는 바뀌지 않고, 결과 확인과 콘텐츠 참여는 추가 날짜를 사용하지 않습니다.

검증: 문법, 기존 엔진, 모든 신규 활동 저장/진행, UP 순위 및 동점 경계, 대사 개수와 사진 매핑 검사 통과.
실제 브라우저 실행 파일 다운로드가 시간 초과되어 화면/오디오 자동 검증은 완료하지 못했습니다.
