캐릭터 애니메이션 업데이트

실행: 새 폴더에 전체 압축을 풀고 game_src/START_GAME.bat를 실행하세요.
기존 서버를 실행 중이면 먼저 해당 명령 프롬프트에서 Ctrl+C로 종료합니다.
브라우저 주소: http://localhost:8000 / 이전 화면이 나오면 Ctrl+F5.
수동 실행: game_src에서 python -m http.server 8000 --directory dist

메인 캐릭터 아래 '캐릭터 설정'에서 기본/꽃무늬 의상과 움직임 강도를 선택합니다.
설정은 브라우저에 저장되며 게임 진행 저장 데이터와 분리되어 있습니다.
기본값: 기본 의상 / 생동감 있게.
24칸 이미지 시트 기반: 눈 깜빡임, 고개 기울임, 손 인사, 기쁨, 미세 호흡.
피곤하거나 좋지 않은 결과에서는 밝은 무작위 손동작 대신 한숨 표정을 사용합니다.
별풍선 리액션 선택 후 메인 화면에서 대응하는 표정/동작을 보여줍니다.
설정/게임 창이 열리거나 다른 탭으로 전환되면 메인 동작을 멈춥니다.
운영체제의 동작 줄이기 설정을 존중합니다.
표정/의상 이미지는 미니게임 옆 표정과 결과 화면에도 적용됩니다.
점프 게임의 전신 플레이어와 크루원의 실제 사진은 기존 구성을 유지합니다.

제작 방식: 제공된 6열 4행 시트의 체크무늬를 연한 분홍 배경으로 정리했습니다.
부위별 레이어가 아닌 완성 포즈 시트이므로 골격 애니메이션이 아닌
포즈 전환과 미세 이동/확대를 조합합니다. 각 프레임은 256×256이며
메인 표시 폭은 최대 420px로 제한합니다. 업스케일로 원본 이상의 디테일을 보장하지 않습니다.
이미지 편집: 내장 이미지 생성/편집 도구.
프롬프트: 체크 배경만 #f4eaf0 단색으로 교체, 1536×1024와 6×4 구도,
24개의 표정/손동작/의상/인물/위치 유지, 글자·테두리 추가 금지.

검증: Node 자동 검사 및 모듈/이미지 포함 확인.
이 환경의 브라우저 설치 시간 초과로 실제 브라우저 화면·오디오 검증은 완료하지 못했습니다.
