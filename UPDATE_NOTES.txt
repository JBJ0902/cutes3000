실행: 기존 서버를 종료한 후 START_GAME.bat 실행 (Python 필요).
또는 dist 폴더에서 python -m http.server 8000 --bind 127.0.0.1 실행.
브라우저: http://localhost:8000 — 새 파일이 안 보이면 Ctrl+F5.
index.html 더블클릭은 JavaScript 모듈 보안 제한 때문에 지원하지 않습니다.
기존 저장은 같은 브라우저와 같은 주소/포트에서 유지됩니다. 교체 전에 메뉴에서 저장 파일을 내보내세요.

음악: 화면 하단에서 7곡 선택, 재생/일시정지/정지, 볼륨, 한 곡 반복.
반복을 해제하면 다음 곡으로 자동 진행합니다. 첫 재생은 직접 버튼을 눌러 주세요.
효과음 볼륨은 상단 사운드 메뉴에서 별도 조절합니다.

표정: 원본 384x512 비율을 유지. 플레이 중 220x293, 결과 320x427(작은 화면에서는 축소).
점프 별 획득: 웃는 표정. 장애물 충돌: 아쉬운 표정. 쇼츠 포착과 신규 게임도 즉시 반응합니다.
결과: 모든 활동에 큰 표정 표시. 성공 기준은 실력 점수 50% 이상입니다.
원본 이미지를 사용하며 새로운 고해상도 이미지를 생성한 것은 아닙니다.

추가 활동: 응원 타이밍 방송(시각 신호에 맞춰 클릭/스페이스), 팬심 기억력 게임(빛나는 순서 재현).
두 활동 모두 35초, 2라운드는 선택, 하루 한 활동. 결과는 팬/체력/화제성/충성도에 반영됩니다.
응원 타이밍은 첨부 노래의 비트 분석에 동기화된 게임이 아니라 독립적인 시각 타이밍 게임입니다.

검증: JavaScript 문법, 기존 엔진 테스트, 신규 활동 저장/46일 진행 테스트, 음악 파일 검사.
이 환경에 브라우저 실행 파일이 없어 실제 브라우저 화면과 재생에 대한 자동 검증은 수행하지 못했습니다.
